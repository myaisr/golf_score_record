# ROUNDNOTE

1ホール終了直後に打数を記録する、スマートフォン向けゴルフスコアアプリです。

## 機能

- 18ホールの入力と前後半集計
- 残り50yまで・50y以内からON・パットの3項目を高速入力
- ティーショット／2打目以降のOB記録
- ティーショットの方向（左・狙いどおり・右）を任意で記録
- 50y以内のミス（ショート・オーバー・左・右・ダフリ・トップ）を複数選択で記録
- 折りたたみ式の振り返りと、記録済みホールだけを対象とした傾向集計
- ボギーオン判定、スコア自動計算
- 入力完了ホールを対象としたボギーオン以内・3パット以上の集計
- ブラウザ内の自動保存（localStorage）
- 結果のPNG画像出力
- PWA対応（ホーム画面への追加・一度開いた後のオフライン表示）

## 起動

`index.html` をブラウザで開くか、ローカルサーバーを起動します。

```bash
python -m http.server 8000
```

`http://localhost:8000/` にアクセスしてください。PWA機能は localhost または HTTPS 上で動作します。

## UIプレビュー

`http://localhost:8000/?preview=1` では、通常のラウンド記録と分けたお試しデータで操作できます。「サンプル」で6ホール分を読み込めます。振り返りは任意で、同じ項目をもう一度押すと解除します。50y以内は「ミスなし」と未記録を区別し、複数選択時の数字は各ミスが出たホール数です。打数も選択済みの数字をもう一度押すと未入力に戻せます。

Node.jsがある場合は `node scripts/preview.mjs` でも起動できます。`node --test tests/app.test.cjs tests/offline.test.cjs` で保存互換性・入力操作・集計・オフライン表示の回帰確認を実行できます。

## 構成

- `index.html`：ページの読み込み
- `app.css`：レスポンシブUI
- `app.js`：入力・保存・集計・PNG出力
- `sw.js`：オフラインキャッシュ

打数の合計・内訳・ボギーオン以内・3パット以上は、3項目すべて入力したホールだけを集計します。OBと任意の振り返りは入力した記録を集計します。50y超から直接ONしたホールのアプローチ記録は傾向集計から除外します。共通の目標値や推定の罰打数は表示しません。

## GitHub Pagesで公開

1. このフォルダのファイルをリポジトリのルートに置いて push します。
2. GitHub の **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。
3. Branch に `main`、フォルダに `/ (root)` を指定して保存します。
4. 公開された URL にスマートフォンでアクセスします。

GitHub Pages は公開サイトになるため、ゴルフ場名などの個人記録はブラウザ内にのみ保存されます。データは端末・ブラウザ間で同期されません。

## 注意

- 現状、複数ラウンドの履歴管理・クラウド同期はありません。新規ラウンドを開始すると以前の入力は置き換わります。結果PNGを保存してください。
- OB罰打は各区間の打数に含めて入力します。OB欄は分析用であり、スコアに再加算しません。
- キャッシュを使うため、更新後はブラウザを再読み込みしてください。
