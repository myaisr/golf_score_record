# ROUNDNOTE

ホール終了後に打数とミスを記録し、ラウンド後に100切りに向けた改善点を振り返るゴルフ記録Webアプリです。

**[アプリを使う](https://myaisr.github.io/golf_score_record/)** 

## 利用する方へ

公開URLをSafariなどのブラウザで開くだけで使えます。ログイン・インストール・PCでの起動操作は不要です。

1. 日付・ゴルフ場を入力します。前後半のコース名も変更できます。
2. 各ホール終了後に「50y以内まで」「50y以内 → ON」「パット」を記録します。罰打は各打数に含め、OB欄には回数だけを入力します。
3. ラウンドを終了すると、総スコア・目標比較・ミスの傾向を確認できます。

ラウンド中は累計スコアを表示しません。使用クラブやショットの振り返りは任意です。

### 記録の保存

記録は各自の端末・ブラウザ内に保存され、他の利用者の記録とは混ざりません。同じ端末・同じブラウザを共有する場合は、同じ記録が見えます。別の端末やブラウザには自動同期されません。

ラウンド後は結果画面の「JSONを保存」でバックアップしてください。全履歴を残していれば、最新版のJSONに過去のラウンドも含まれます。「履歴」→「JSON復元」で別端末へ移せます。サイトデータを削除すると記録も消えるため、JSONは端末外にも保管してください。
