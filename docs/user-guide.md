# 使い方

[アプリを開く](https://myaisr.github.io/golf_score_record/) · [READMEに戻る](../README.md)

公開URLを開くだけで使えます。ホーム画面への追加は任意です。開発用のNode.jsやPythonは不要です。

## 入力とラウンド終了

- 打数は「50y以内まで」「50y以内 → ON」「パット」の3項目です。選択済みの数字を再タップすると未入力に戻せます。大きい値は `− / ＋` で調整します。
- 未入力と0打は別の記録です。3項目すべてを入力すると、そのホールの打数が確定します。
- 「50y超からON」では、50y以内の打数を0にします。「50y以内まで」には直接ONまでの全打数を記録します。直接ON後に50y以内の打数を正の数に訂正すると、直接ONを解除します。
- OBは「ティーショット」「2打目以降」の回数を記録します。罰打は3項目の該当する打数に含め、OB欄ではスコアに再加算しません。
- 振り返りは任意です。ティーの「左・まっすぐ・右」は相互排他で、「ショート」は独立して併用できます。ショート単独も記録できます。チョロ・ダフリなど、著しい飛距離不足はショートに含めます。
- 使用クラブは「ドライバー／ウッド・ユーティリティ／アイアン／ウェッジ」の任意4択です。選択済みのボタンを再タップすると解除します。Excelのホール別記録には「ティー使用クラブ」列を追加します。PNGでは `1W / W/UT / I / WG` と略記します。
- 50y以内の振り返りは方向・ダフリ・トップを複数選択できます。未記録と「ミスなし」は区別します。

ラウンド中は現在のホールの打数と入力済みホール数だけを表示し、累計スコア、OUT/IN小計、累計対Parを表示しません。「集計」を開いても、終了操作までは累計を表示しません。履歴一覧にもスコアを表示しません。

18Hの「ラウンド終了」、または集計画面の「ラウンドを終了して集計」で結果を表示します。未入力がある場合は確認後に途中終了できます。結果の「記録を再開」でラウンド中に戻すと、累計の表示を再び隠します。

## 結果と目標設定

結果には総スコア、前後半のスコア、対Par、目標との差分、OB内訳、50y以内の2打以上率、直接ON、ティーショットの傾向、ホール別スコアカードを表示します。

スコアカードは画面・PNGともに、ダブルボギーを薄いオレンジ、トリプルボギー以上を薄い紫背景と濃い紫文字で表示します。OB1回以上、3パット以上、50y以内からONまで2打以上はオレンジ系の色で表示します。「50yまで」は、OB1回につき2打（OBになった1打＋罰打1打）を差し引き、50y以内から1打でONしてもボギーオンに届かない場合にオレンジ系で強調します。直接ONの場合は、差し引いた後のONまでの打数で判定します。例えばPar4で50yまで4打・OB1回なら強調なし、5打・OB1回ならオレンジです。

「目標設定」で以下を変更・保存できます。設定はアプリ全体で共有し、過去のラウンドにも現在の目標を使用します。

| 指標 | 初期目標（18H） | 差分の良否 |
| --- | --- | --- |
| 総スコア | 99打以下 | 実績−目標が0以下 |
| OB回数 | 2回以下 | 実績−目標が0以下 |
| 50y以内からの2打以上率 | 30%以下 | 実績−目標が0pt以下 |
| パット数 | 36打以下 | 実績−目標が0以下 |
| ボギーオン以内率 | 12H以上 / 18H（約66.7%） | 実績−目標が0pt以上 |

各目標は分析用の初期値です。指標の目標値を足して総スコア目標を作ることはありません。

「18H / 前半のコース名 / 後半のコース名」で比較範囲を切り替えます。前後半の打数・OB目標は18Hの半分です。総スコアの整数の端数は前半へ配分し、初期値99打なら前半50打、後半49打になります。2打以上率の目標は共通、ボギーオン目標は18Hのホール数を率に換算します。

途中終了では、実績は入力完了分だけを表示します。総スコア・OB・パットの目標差分は対象の18Hまたは9Hが揃うまで「入力不足」とし、達成・未達を判定しません。率は対象がある場合に計算し、分母が0なら「対象なし」です。「50yまで」の目標設定・比較は廃止し、打数の入力・詳細記録は維持しています。

記録画面の日付・ゴルフ場の下で、前半・後半のコース名をそれぞれ20文字まで自由に入力できます。初期値はOUT／INです。IN／OUTや東／西などに変更でき、入力中・結果・比較タブ・PNG・JSON・Excelに反映します。先に回る9Hを前半、後に回る9Hを後半として記録し、ホール番号は入力順の1〜18です。旧データで名前がない場合はOUT／INを補います。

### ティーショットの方向とクラブ

「ショットの傾向」の横向き積み上げ棒は、クラブ4カテゴリを色分けし、ティーショットでOBがあった部分に斜線を表示します。数字はホール数で、同じホールで複数回OBしても「OBあり1H」です。2打目以降のOBはこの判定に含めません。

クラブのボタンをタップすると、複数カテゴリを選んで表示できます。「すべて」で全選択に戻り、横軸の目盛りは切り替えても固定です。クラブ未記録の方向データは「すべて」で灰色表示し、方向未記録の件数は別に表示します。絞り込みはこのグラフだけに適用され、総スコア・OB内訳・ショート率・記録データは変わりません。ラウンドの切り替えや再読み込みで全選択に戻ります。

保存するスコアカードPNGにも、選択中のクラブとOBの内訳を反映します。

### 結果PNG

「画像を保存」から、分析とスコアカードを2枚のPNGとして保存できます。各画像は1200×1600pxです。目標比較、OB内訳、アプローチ成績、前後半の比較を分析画像にまとめ、18Hの詳細はスコアカードに残します。

iPhoneでは、保存したい画像の「保存メニューを開く」を押し、端末のメニューから「画像を保存」（または「写真に保存」）を選んでください。分析・スコアカードはそれぞれ保存します。ブラウザから写真アプリへ自動で追加する方式ではありません。

保存メニューが表示されない場合は、プレビュー画像を長押しして保存してください。「PNGをダウンロード」はファイルとして保存する操作です。

## 履歴とバックアップ

「新規ラウンド」で今の記録を残して次のラウンドを開始します。途中のラウンドも「履歴」から開けます。

### JSONを保存する

結果画面の「JSONを保存」、または「履歴」→「JSON出力」で、全ラウンドと目標設定をまとめて保存できます。全履歴をアプリに残していれば、最新版のJSONだけで復元やExcel取り込みができます。

### JSONから復元する

「履歴」→「JSON復元」でファイルを選びます。既存のラウンドに追加・更新する方式で、同じラウンドは重複しません。同じIDの記録は更新日時が新しいものだけを反映し、JSONにない既存の記録は残します。

旧版のJSONも読み込めます。前後半のコース名がない場合はOUT／INを補い、廃止した「50yまで」の目標値は読み飛ばします。打数などの記録は引き継ぎます。既存の記録がある場合、選択中のラウンドと目標設定は維持します。空の初期状態ではバックアップの設定を引き継ぎます。

復元ファイルは15MB以下、履歴は最大2000ラウンドです。実際に保存できる件数は端末の容量によって異なります。

### 保存先について

データは各自の端末・ブラウザ内に保存します。同じURLを複数人が開いても混ざりません。同じ端末・同じブラウザを共有する場合は同じ記録が見え、別の端末・ブラウザには自動同期されません。ローカルのURLと公開URLも別の保存先です。

サイトデータの削除、長期未使用、端末の容量不足などで記録が消える場合があります。JSONはラウンド後に端末外にも保管してください。PNGは閲覧用で、JSONからの復元の代わりにはなりません。プライベートブラウズでは記録を残せない場合があります。

## オフラインで使う

初回はオンラインで開いてください。アプリのファイルの保存が完了すると、オフラインでも入力・集計・PNG保存・JSON出力ができます。更新を受け取るときは、オンラインで再読み込みしてください。

iPhoneではホーム画面に追加して使うこともできます。追加した場合はそのアイコンから一度オンラインで開き、ラウンド前に機内モードで開き直せることを確認してください。

## Excelで分析する

任意で、保存したJSONからExcelを作成・更新できます。PCでPythonスクリプトを実行する必要があります。アプリのJSON保存だけではExcelは自動更新されません。
