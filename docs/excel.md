# Excelへの取り込み・更新

[READMEに戻る](../README.md) · [アプリの使い方](user-guide.md)

Excelで分析したい方向けの任意機能です。公開アプリを利用するだけなら、PythonやExcelの準備は不要です。アプリからJSONを保存してPCでスクリプトを実行すると、Excelを新規作成・更新できます。

## 初回の準備

このリポジトリをPCに取得し、作業フォルダへ移動してください。取得方法は[開発手順のローカル起動](development.md#ローカル起動)を参照してください。Webサーバーの起動は不要です。

PCにPython 3を用意し、依存ライブラリをインストールします。

```bash
python -m pip install -r requirements-excel.txt
```

## ラウンド後の更新

結果画面の「JSONを保存」、または「履歴」→「JSON出力」で保存したファイルを `backups/` に置き、次を実行します。

```bash
python scripts/import_rounds.py backups/roundnote-backup-2026-11-01.json --output outputs/roundnote.xlsx
```

ファイル名は手元のバックアップ名に置き換えてください。同じ出力先で再実行すると、Excel内の既存ラウンドとマージして更新します。Excelファイルを閉じてから実行してください。同一IDは更新日時が新しいものだけを反映し、同時刻・古いJSONで戻しません。別IDの記録は残します。

全履歴をアプリに残していれば、入力は最新版のJSONだけで十分です。過去ラウンドをアプリから削除した場合は、その記録は新しいJSONには含まれません。既存のExcelにある別IDのラウンドは維持されます。

## 生成される内容

生成するシートは次の3つです。

| シート | 内容 |
| --- | --- |
| 分析ダッシュボード | スコア、OB方向別内訳、ティーショート率、50y以内2打以上率、パット、ボギーオン率の推移。直近5Rと前5Rの平均・変化 |
| ラウンド履歴 | 日付・ゴルフ場・終了状態・打数・対象数・率・前後半のコース名・スコアなどのラウンド単位の記録 |
| ホール別記録 | 18Hの打数、ティー方向とショート、直接ON、OB、振り返り、集計用の計算列 |

ダッシュボードは6つのExcelグラフを持ち、履歴の数式・値から更新されます。推移と直近5R比較は **終了済みかつ18H入力完了** のラウンドだけが対象です。途中・未終了ラウンドは履歴とホール別記録に残し、成長推移から除外します。

直近5Rと前5Rは、それぞれ最大5件です。比較する前の期間がなければ変化は空欄になります。打数・OBはラウンド平均、割合は対象数の合計を分母にした加重集計です。旧記録のショート有無不明はホール別記録でも空欄に保ち、ショート率の対象数から除外します。対象数0の率は0%にせず空欄、率の変化はパーセントポイント（pt）で表示します。ラウンド順は日付、作成日時の順です。

Excelには再取り込み用のラウンドJSONを履歴の非表示列に保持しています。取り込み時には3シートを再生成するため、Excelへの手修正や独自のグラフは置き換わります。Excelからアプリへ書き戻す機能はありません。元のJSONバックアップを保存し、独自分析は別ブックで行ってください。Excelファイルは公開Gitリポジトリの管理対象から除外しています。

## ファイルの保存先

- `backups/`：アプリから保存したJSON
- `outputs/`：作成・更新したExcel

フォルダがなければ作成してください。Excelの出力先フォルダはスクリプトでも作成します。両フォルダ全体と、作業フォルダ内のJSON・Excelファイルは `.gitignore` で除外しています。ルート直下に保存したファイルも対象です。記録データはGitHubへ追加しないでください。
